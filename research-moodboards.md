### 1.1 Who They Are

A **booth fabricator/carpenter** is the hands-on builder who constructs trade show booths for larger design agencies (like Skyline, Classic Exhibits, Exhibitus). They are NOT the full-service experiential agency. They are:

- The workshop with sawdust on the floor
- The team cutting wood, welding metal, printing graphics
- The B2B partner behind the scenes

**Key differentiator from big agencies:** You sell CRAFTSMANSHIP, not strategy. You sell RELIABILITY, not creativity. Your client is another company's project manager, not a marketing director.

### 1.2 Website Goals

| Goal | Priority |
|------|----------|
| Showcase past work (portfolio/gallery) | HIGHEST |
| Communicate trust and professionalism | HIGH |
| Explain capabilities clearly | HIGH |
| Make it easy to contact/request quote | MEDIUM |
| Differentiate from competitors | MEDIUM |
| Rank for local SEO | MEDIUM |

### 1.3 Mandatory Sections for a Single Landing Page

```
1. [HERO]          - Company name, tagline, 1 CTA button
2. [ABOUT]         - 2-3 sentences, who you are, what you build
3. [CAPABILITIES]  - 4-6 capability cards (wood fab, metal fab, graphics, assembly, etc.)
4. [PORTFOLIO]     - Grid of project images (THE MOST IMPORTANT SECTION)
5. [PROCESS]       - 3-4 step visual process flow
6. [TRUST SIGNALS] - Client logos, certifications, or testimonials
7. [CONTACT / CTA] - Contact form or quote request
8. [FOOTER]        - Address, phone, email, social links
```

Total page length: ~5-7 scroll folds. Keep it tight -- fabricators' clients want to see WORK, not read essays.

### 1.4 What TO DO (Design Best Practices)

**DO:**
- Lead with high-quality project photography (real booths you've built, not stock)
- Use a clean, structured grid layout (WordPress/agency feel, not scattered)
- Keep navigation minimal (3-5 items max on a single-page site)
- Use industry-appropriate language: "CNC Routing," "Custom Millwork," "Metal Fabrication," "Finishing"
- Include a dedicated gallery section with lightbox/fullscreen image viewing
- Show workshop/process photos alongside finished product (tells the craftsmanship story)
- Use clear, legible fonts with generous whitespace
- Have ONE primary CTA repeated (e.g., "Request a Quote" or "Work With Us")
- Optimize all images for fast loading
- Include trust signals: years in business, number of projects, client names
- Ensure mobile responsiveness (project managers browse on phones)

**DO NOT:**
- Over-animate -- parallax scrolling, excessive fade-ins, scroll-jacking scream "vibe coded"
- Use generic stock photography of people shaking hands in suits
- Write long paragraphs -- fabricators' clients scan, they don't read
- Use trendy design gimmicks (glass morphism, neon gradients, brutalism)
- Auto-play videos with sound
- Hide important info behind hovers or clicks
- Use thin/light fonts at small sizes (fabricators are practical people, not design snobs)
- Over-engineer the hero with rotating carousels (one strong image is better)
- Use cheap-looking icon sets (stick to simple, clean icons or none at all)
- Make the contact form longer than 4-5 fields

### 1.5 Typography

**For the booth fabrication industry, typography should communicate:**
- Stability (bold, grounded)
- Precision (clean, well-spaced)
- Craftsmanship (not overly decorative)

**Recommended font pairings:**

| Heading | Body | Vibe |
|---------|------|------|
| **Montserrat** (bold) | **Open Sans** | Modern, approachable |
| **Playfair Display** | **Lato** | Elegant, traditional |
| **Oswald** | **Roboto** | Bold, industrial |
| **Inter** | **Inter** | Clean, versatile (single family) |
| **Raleway** | **Work Sans** | Polished, professional |

**Font sizing rules:**
- H1 (hero heading): 48-64px on desktop
- H2 (section titles): 32-40px
- H3 (card/subsection titles): 20-24px
- Body text: 16-18px (never below 14px)
- Line height: 1.5-1.6 for body, 1.2 for headings
- Keep maximum line length at 65-75 characters for readability

### 1.6 Color Theory

**Industry color psychology for fabrication/building trades:**

| Color | Psychology | Best Use |
|-------|-----------|----------|
| **Navy / Dark Blue** | Trust, stability, professionalism | Primary brand color |
| **Charcoal / Dark Gray** | Industrial strength, seriousness | Backgrounds, text |
| **Warm Wood Tones (#C4956A)** | Craftsmanship, natural, handmade | Accents, dividers |
| **Orange / Amber** | Energy, action, urgency | CTA buttons |
| **White / Off-White** | Clean, spacious, organized | Backgrounds |
| **Steel Gray** | Precision, metal work | Secondary accents |
| **Forest/Sage Green** | Sustainable, quality | Optional accent |

**What to avoid:**
- Bright neon colors (not professional)
- Pastels (too soft for fabrication)
- Pure black #000000 (too harsh -- use #1a1a1a or #111)
- Too many colors (3-4 max including neutrals)

### 1.7 Portfolio/Gallery Strategy

This is THE critical section. Here's how to structure it:

**Layout options:**
1. **Masonry grid** -- Mixed aspect ratios, feels organic, good for varied project photos
2. **Uniform grid (3-column)** -- Clean, organized, WordPress classic feel
3. **Full-width horizontal scroll** -- Immersive but can feel "vibe coded" -- use carefully

**Each project card should show:**
- High-res project photo (ideally the booth on a show floor with good lighting)
- Project name/client name (e.g., "20x20 Island for TechCorp at CES")
- Optional: Material tags (Wood, Metal, LED, Fabric)

**Image best practices:**
- Show the booth fully assembled at the show (proves it was delivered)
- Show workshop/construction shots (proves YOU built it)
- Avoid renderings only -- real photos build real trust
- Use consistent aspect ratios for a clean grid
- Compress images (target <200KB each) without sacrificing quality


### Technical Implementation Notes

- **Tech stack recommendation:** Plain HTML/CSS/JS (mimics WordPress output without WordPress)
- **CSS framework:** Consider a minimal utility approach or Bootstrap 5 for the WordPress feel
- **Image handling:** Pre-compress all portfolio images, use WebP format with JPEG fallback
- **Mobile:** Stack grids to 1-2 columns, collapse nav to hamburger
- **Performance:** No heavy JS frameworks, keep page under 1MB total
- **SEO:** Semantic HTML5 tags (header, section, footer), descriptive alt text on all project images
